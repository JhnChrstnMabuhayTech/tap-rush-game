# Tap Rush

A Facebook Instant Game with a backend for its leaderboard.

A round lasts 30 seconds. Circles appear and shrink, and tapping one scores a point.

> Work in progress. Setup, architecture, and design notes will be added as the project takes shape.

## Repository layout (planned)

```
apps/game/        Instant Game client
apps/server/      Leaderboard backend
packages/shared/  Code shared between client and server
```
