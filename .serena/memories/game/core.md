# apps/game

- `index.html` loads the Instant Games SDK 8.0 script, then `src/main.ts`. `public/fbapp-config.json` (`NAV_BAR`) is copied to the build root.
- `src/main.ts`: toggles the kit's `.gc-letterbox` (9:16 frame) only for a fine pointer + viewport wider than 9:16; phones and narrow windows get the whole screen. `boot()`: `platform.initialize()` → progress 50 → wait ≤ 1.5 s for the title font → progress 100 → `platform.start()` → title screen.
- `src/platform/`: `Platform { kind, initialize, setLoadingProgress, start }`. `detectPlatform()` uses the real SDK only when `window.FBInstant` exists and the page is iframed (Facebook always embeds the game), or `?platform=facebook`; otherwise the local stand-in, because `initializeAsync` never resolves in a top-level tab. `choosePlatform()` is the pure, tested decision. Add SDK members to the hand-written `FBInstantSDK` type as they're used.
- `src/kit/`: vendored UI kit — `bundle.js` (classic script assigning `window.Glowcatch`), `bundle.css`, `index.d.ts`, `tokens.json`, generated `tokens.css`. Re-sync steps in `src/kit/README.md`; `scripts/tokens-css.test.ts` fails on any drift.
- Kit usage: screens over the field are a `PlayField({ ambient: true })` with a child carrying class `screen` (absolute, `z-hud`). Stateful components expose `update()`; `PlayField` has `stop()` (cancel its rAF before replacing it).
- The kit's copies of the rules (`CURVE`, `BONUSES`, `comboFor`, `pointsFor`) and its `PlayField` demo loop are reference only — frame-rate dependent, pixel-based, coarse RNG — and are never used for scoring. Gameplay must come from `@glowcatch/shared`. Until the game loop exists, Play runs the kit demo as a labelled placeholder.
- Facebook constraints (SDK 8.0, D11): no `getName`/`getPhoto`; leaderboard names/photos only via overlay views (XML + CSS in the bundle, fed player IDs); network only to CSP-allowlisted domains (the backend) — no CDNs at runtime; the kit's `bundle.css` still `@import`s Google Fonts (to be replaced by a self-hosted woff2, review notes G4/G6); share images carry no player name.
- Release: `pnpm --filter @glowcatch/game bundle` → zip with `index.html` + `fbapp-config.json` at root → App Dashboard → Web Hosting → upload → Stage for testing. Never Push to production.
