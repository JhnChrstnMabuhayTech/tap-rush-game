# apps/game

- `index.html` loads the Instant Games SDK 8.0 script, then `src/main.ts`. `public/fbapp-config.json` (`NAV_BAR`) is copied to the build root.
- `src/main.ts`: toggles the kit's `.gc-letterbox` (9:16 frame) only for a fine pointer + viewport wider than 9:16; phones and narrow windows get the whole screen. `boot()`: `platform.initialize()` → progress → wait ≤ 1.5 s for the title font → `platform.start()` → `startApp(root, platform)`.
- `src/app.ts`: the screen flow (title → countdown → playing ⇄ paused → over), one screen at a time, layers via `.gc-layer` inside the play frame. Pause sources: HUD button, Escape, `visibilitychange`, `platform.onPause`; ignored once the round has ended (last fireflies fading). Resume always goes through a fresh 3-2-1; the clock starts on "Go!". Game over appends a Home ghost button (`.gc-over-home`, spans the actions grid) and Escape there goes home.
- `src/round/`: `play.ts` builds the frame (canvas, `.gc-fx`, kit `ScoreHud`), creates a shared `Round` with the field measured at start, steps it with `stepper.ts` (frame time → 10 ms ticks, max 10 per frame), maps `pointerdown` through `field.ts` (`toLogical`, 0.1-unit rounding), draws with `kit.drawField`/`drawFirefly` from round state only, and turns events into popups/banners via `feedback.ts` (pure, tested). After the end it keeps stepping only to fade the last fireflies.
- `src/audio/`: `notes.ts` (pure, tested: G major pentatonic chime ladder, combo notes, pad notes) and `sound.ts` (Web Audio engine: catch chimes per kind, last-5-seconds tick, round end, ambience = pad + crickets, shared reverb, master compressor). No AudioContext until `unlock()` inside a gesture (app.ts listens to pointerdown/pointerup/touchend/click/keydown; iOS needs touchend/click); calls before that are silent. `createSound(storage, createContext)`: the context is injectable (used to record and measure the mix). Mute is remembered as `glowcatch.sound`. Ambience runs only while the clock runs. Levels were tuned by measurement (chime peaks ≈ 0.43, ambience ≈ 16 dB under); re-measure after changing gains.
- `src/title/`: the title's own interactive field (replaces the kit's ambient PlayField, D14): catchable fireflies above the name (spawn area measured from `.gc-title-name`), Lantern/Frost/Swarm visitors in turn that name themselves, a one-time "Tap a firefly" hint, a moon. Nothing is scored. The title menu has `is-passthrough` so taps reach the canvas; `onEager` adds `is-eager` after three catches. Dev hook: `window.glowcatch.title().fireflies`.
- `src/badges/`: seven score badges (D15). `badges.ts` is pure and derives everything from the best score (`earnedBadges`, `unlockedBadges(previousBest, score)`, `nextBadge`, `progressToNext`): no separate storage. `badge-view.ts` draws medallions (a firefly of the badge's kind on a disc, lit if earned; locked ones get a `sky-deep` veil because `drawFirefly` sets its own alpha) and builds the collection sheet, the game-over "New badge" card and the next-badge line. app.ts adds "Badges n/7" to the title actions (screen `'badges'`, Escape closes) and inserts the card or line before `.gc-over-actions`. Thresholds came from simulated player models; revisit with real scores.
- `src/storage/best.ts`: best score in `localStorage` (`glowcatch.best`), safe when storage throws; 0 means no best (never show "Best 0").
- `src/platform/`: `Platform { kind, initialize, setLoadingProgress, start, onPause, share }`. Real SDK only when `window.FBInstant` exists and the page is iframed (or `?platform=facebook`); otherwise the local stand-in. `share` resolves on cancel (SDK 8.0 behaviour); only rejection shows "Couldn't open sharing.". Add SDK members to the hand-written `FBInstantSDK` type as they're used.
- Dev-only hook: `window.glowcatch.current()` returns the live `Play` (`.round`, `.frame`) and `window.glowcatch.sound` the sound engine, for browser automation; it's behind `import.meta.env.DEV` and absent from production bundles.
- `src/kit/`: vendored UI kit (`bundle.js` on `window.Glowcatch`, `bundle.css`, `index.d.ts`, `tokens.json`, generated `tokens.css`). Never edit; re-sync per `src/kit/README.md`. Its rule copies and `PlayField` are not used: play draws its own field with `drawField`/`drawFirefly`, and so does the title (`src/title/`). Busy state on an already-rendered kit button: toggle `gc-btn-busy` + `disabled` (see `setBusy` in app.ts).
- Seeds are local (`crypto.getRandomValues`) until the server issues rounds; scores stay on the device until then.
- Facebook constraints (SDK 8.0, D11): no `getName`/`getPhoto`; leaderboard names/photos only via overlay views; network only to CSP-allowlisted domains; the kit's `bundle.css` still `@import`s Google Fonts (to replace with a self-hosted woff2, review notes G4/G6); share images carry no player name.
- Release: `pnpm --filter @glowcatch/game bundle` → zip → App Dashboard → Use cases → Launch an Instant Game → Customize → Web hosting → Upload Version (comment starts with the commit) → Stage for testing. Never Push to production. App ID 1377676130860334.
- Countdown (`countdown()` in app.ts): the kit's `Countdown` per step, `sound.countdown(step)` (pips climbing D, E, G, then a G strum on "Go!"), a CSS ring on the numeral (`.gc-countdown b::before`, ink; glow burst on "Go!"), and a vibration on "Go!". The clock starts on "Go!".
