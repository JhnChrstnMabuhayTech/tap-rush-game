# apps/server

- Cloudflare Worker: `wrangler.jsonc` (name `glowcatch-api`, main `src/index.ts`, D1 binding `DB` → database `glowcatch`, `migrations_dir: migrations`). `src/index.ts` default-exports `{ fetch }` `satisfies ExportedHandler<Env>` and routes on method + pathname. `src/http.ts`: `json()`, `fail(status, code)` → `{ error }` (codes in shared `ApiErrorCode`), `readJson(request, maxBytes)` (undefined if not JSON or too big).
- Bindings (`src/env.ts`): `DB`, `APP_SECRET` (secret), `ALLOW_UNSIGNED` (only `.dev.vars`).
- Built: `GET /health` → `{ ok: true, rulesVersion }`; `POST /v1/rounds` (`src/rounds.ts`): body `{ signature, field }` (shared `StartRoundRequest`; field sides 100–4096, top ≤ height/2; body ≤ 4 KB) → 201 `{ roundId, seed, rulesVersion, expiresAt }` (uuid, 32-bit seed from `crypto.getRandomValues`, `ROUND_TTL_MS` 15 min). One D1 batch: upsert player (best 0), close the player's open rounds (`rejected`/`superseded`), insert the round. So the game must submit a finished round before starting the next. `POST /v1/rounds/{uuid}/score` (`src/score.ts`, `SCORE_PATH` regex in index.ts): body `{ signature, taps, score }` (≤ 64 KB, ≤ `MAX_TAPS` 1000, ticks non-decreasing integers 0..`MAX_ROUND_TICKS`, |coord| ≤ 1e5, score safe int ≥ 0) else 400 with the round left open; signature must verify with `request_payload === roundId` else 401; round missing or another player's → 404. Not `issued` → same answer again, nothing changes. Else `judge()` in order: `expired` (now > expires_at, not replayed), `rules_version` (not replayed), replay → `late_taps`, `mismatch` (claimed ≠ replayed), `too_fast` (now − issued_at < ticks×10 ms − 1 s), then `implausibility()` (`src/plausibility.ts`: `reaction` = more than max(3, 10% of catches) caught < 120 ms after spawn; `tap_rate` = > 25 taps in any 100-tick window). One batch: `UPDATE rounds … WHERE status = 'issued'` (taps normalised to {tick,x,y} JSON, server score, status ranked|rejected, reason) + if ranked `UPDATE players SET best … WHERE best_score < score AND EXISTS(round ranked with this score and submitted_at)` so racing submissions can't overwrite or lift the best. Answer 200 `{ status, score, best, rank }` re-read after the batch; rank = 1 + players with a higher best (ties share), null while best is 0. Anything else → 404 `not_found`.
- Identity (`src/player.ts`): `verifySignedPlayerInfo(signed, { secret, allowUnsigned }, now)` parses `<sig>.<payload>` (base64url JSON: algorithm, issued_at s, player_id `/^[\w-]{1,64}$/`, request_payload string|null), checks the HMAC-SHA256 with `crypto.subtle.verify` (constant time), algorithm, freshness (≤ 5 min old, ≤ 1 min ahead) → `{ ok, player: { id, requestPayload } }` or `{ ok: false, reason }`. `identify(signed, env, url, now)` adds the dev path: `unsigned.<payload>` only if `allowsUnsigned(env, url)` = `ALLOW_UNSIGNED === 'true'` and host is localhost/127.0.0.1. A test fails if `wrangler.jsonc` sets `"ALLOW_UNSIGNED":`.
- Data (`migrations/0001_init.sql`): `players` (id, best_score default 0, best_at, updated_at; index best_score DESC, best_at ASC) and `rounds` (seed, rules_version, field_w/h/top, issued_at, expires_at, submitted_at, taps JSON, score = server replay, status issued|ranked|rejected, reject_reason; index player_id, status). Times in ms. Never names or photos (SDK 8.0, D11).
- Tests run inside workerd via `@cloudflare/vitest-plugin` (`vitest.config.ts`: `cloudflareTest` with the wrangler config, bindings `APP_SECRET: 'test-app-secret'` and `TEST_MIGRATIONS` from `readD1Migrations`). `src/test/setup.ts` runs `reset()` + `applyD1Migrations` before each test. Tests import `env` from `cloudflare:workers` (typed by `src/test/env.d.ts`) and call `worker.fetch(request, env)`; `src/test/sign.ts` has `playerInfo()`, `signPlayerInfo()`, `encodePlayerInfo()`. `src/test/play.ts` `playRound(config, { reactionMs = 400, gapMs = 150 })` plays a real round through `Round` (honest pace scores 191–305 over 500 seeds, never flagged; `reactionMs: 0, gapMs: 0` is always flagged `reaction`). Score tests start rounds in the past by calling `startRound(request, env, at)` directly, so a full round can be submitted at once. Each score check was mutation-tested (removing it fails a test), including the two race guards via concurrent submissions in both orders. `?raw` imports are typed in `src/test/raw.d.ts`.
- Local dev: `apps/server/.dev.vars` (gitignored) with `APP_SECRET` and `ALLOW_UNSIGNED=true`; `wrangler d1 migrations apply glowcatch --local` once; `wrangler dev` on :8787. Stopping a background `wrangler dev` can leave workerd on 8787: kill the whole tree from the bash/npx parent.
